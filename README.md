# DOKUMENTASI MATERI WORKSHOP 

Prompt Engineering adalah cara menyusun instruksi agar AI dapat memberikan jawaban yang tepat, relevan, dan sesuai dengan kebutuhan pengguna.

Prompt merupakan masukan atau instruksi yang diberikan kepada AI untuk mendapatkan hasil tertentu. Bentuknya bisa berupa pertanyaan, kata kunci, instruksi, maupun potongan kode.

# Struktur Prompt yang Baik

Ada empat bagian utama dalam menyusun prompt:
- Role: Menentukan peran AI yang diinginkan.
- Task: Menjelaskan tugas yang harus dilakukan AI.
- Context: Memberikan informasi atau latar belakang agar AI memahami kebutuhan.
- Format: Menentukan bentuk hasil yang diharapkan.


# Keuntungan Prompt Engineering

Meningkatkan kualitas hasil AI.
Mengurangi kemungkinan jawaban yang tidak sesuai.
Memberikan kontrol lebih baik terhadap hasil AI.
Membantu menghasilkan jawaban sesuai kebutuhan.

# Pengenalan Git Apasih itu git??

Pengertian Git
Git adalah Version Control System (VCS) yang digunakan untuk mencatat dan mengelola perubahan pada file atau proyek.
Git membantu pengguna mengetahui siapa yang melakukan perubahan, kapan perubahan dilakukan, dan bagian apa yang mengalami perubahan.
Git dikembangkan oleh Linus Torvalds pada tahun 2005.

Fungsi Git

Melacak perubahan file.
Menyimpan riwayat perubahan proyek.
Memudahkan pengelolaan kode.
Membantu mengembalikan proyek ke versi sebelumnya.
Mendukung pengerjaan proyek secara kolaboratif.


Perbedaan git dan juga github

Dapat digunakan secara lokal
Berjalan melalui perintah Git

untuk github yaitu

lalu yang jadi pembeda yaitu Git merupakan alat untuk mengelola perubahan proyek, sedangkan GitHub merupakan platform untuk menyimpan dan membagikan proyek yang menggunakan Git.

GIT WORKFLOW
- Working Directory
  Working Directory merupakan salinan proyek yang sedang dikerjakan pada komputer. Di bagian ini, pengguna dapat membuat, mengubah, dan menghapus file.
  
- Staging Area
  Staging Area merupakan tempat untuk menyimpan informasi perubahan yang akan dimasukkan ke dalam commit berikutnya.
  Pengguna dapat menentukan perubahan mana saja yang akan disimpan.\
  
- Git Directory (Repository)
  Git Directory merupakan tempat Git menyimpan metadata dan object database dari sebuah proyek. Bagian ini menyimpan informasi yang dibutuhkan Git untuk mengelola   perubahan proyek.


PERINTAH DASAR GIT

git init: Membuat repository Git baru pada direktori proyek.

git add .: Menambahkan perubahan file ke Staging Area.

git add --all: Menambahkan seluruh perubahan ke Staging Area.

git add -A: Memiliki fungsi yang sama dengan git add --all.

git add *: Menambahkan file yang sesuai dengan pola wildcard ke Staging Area.

git commit -m "message": Menyimpan perubahan ke dalam repository dengan pesan commit.

git remote add origin : Menghubungkan repository lokal dengan repository remote.

git push origin main: Mengirim commit pada branch main ke repository remote.

git pull origin main: Mengambil perubahan dari branch main pada repository remote dan menggabungkannya ke branch aktif.

git clone : Menyalin repository remote ke komputer lokal.



# PENGETAHUAN YANG BARU DIPELAJARI

- Prompt Engineering: Instruksi yang jelas dan memiliki konteks dapat membantu AI menghasilkan output yang lebih sesuai dengan kebutuhan.

- Context dalam AI: AI membutuhkan informasi pendukung agar dapat memahami tujuan dari suatu instruksi dengan lebih baik.

- Git: Version Control System yang membantu melacak dan mengelola setiap perubahan dalam proyek.

- GitHub: Platform online untuk menyimpan repository Git serta mendukung kolaborasi pengembangan proyek.

- Git Workflow: Proses pengelolaan perubahan melalui Working Directory, Staging Area, dan Git Directory.

- Commit: Setiap commit menjadi catatan perubahan yang telah disimpan dalam repository.
